# Threat Feed Relay

외부 위협 Feed의 IP·CIDR·Domain·URL을 수집·정규화·보강하고,
정책에 따라 Profile별 Output Feed로 재배포하는 플랫폼을 개발합니다.

현재는 **구현 전 개발 문서 초안**입니다. 실행 가능한 애플리케이션·설치 구성·기능 테스트는 없습니다.
문서의 기능 설명은 개발 범위이며 현재 제공되는 제품 기능을 뜻하지 않습니다.

개발 자료는 [docs/development](docs/development/README.md)에서 관리합니다.
[요구사항](docs/development/requirements.md)부터 읽고,
[개발 절차·결정 로그](docs/development/workflow.md)에 따라 작업 범위와 남은 결정을 확인하세요.

프로젝트 라이선스는 미정이며 공개 열람과 별도로 수정·재배포 허용 정책은 확정되지 않았습니다.
외부 Feed의 이용·재배포 조건은 프로젝트 문서의 공개 여부와 별개로 확인해야 합니다.
